# ast-predicate

Framework-agnostic TypeScript predicate AST utilities for building, validating, and transforming filter expressions.

The package provides a small typed AST for predicate/filter expressions. It does not depend on a database, ORM, query builder, or runtime framework.

## Installation

```bash
npm install ast-predicate
```

## Basic usage

```ts
import { AstPredicate } from 'ast-predicate';

const predicate = AstPredicate.and(
    AstPredicate.eq('status', 'ACTIVE'),
    AstPredicate.isNull('deletedAt'),
);
```

The generated AST is plain JSON-compatible data, except when using `Date` values.

```ts
{
    type: 'logical',
    op: 'and',
    conditions: [
        {
            type: 'comparison',
            column: 'status',
            op: 'eq',
            value: 'ACTIVE',
        },
        {
            type: 'comparison',
            column: 'deletedAt',
            op: 'isNull',
        },
    ],
}
```

## Direct imports

```ts
import { and, eq, isNull } from 'ast-predicate';

const predicate = and(
    eq('status', 'ACTIVE'),
    isNull('deletedAt'),
);
```

## Typed columns

You can type predicate nodes by a column-name union.

```ts
import { AstPredicate } from 'ast-predicate';
import type { AstPredicateNode } from 'ast-predicate';

type ProductColumn = 'code' | 'name' | 'status' | 'deletedAt';

const predicate: AstPredicateNode<ProductColumn> = AstPredicate.and(
    AstPredicate.eq('status', 'ACTIVE'),
    AstPredicate.isNull('deletedAt'),
);
```

Invalid column names are rejected when the result is checked against the typed node.

```ts
const predicate: AstPredicateNode<ProductColumn> = AstPredicate.isNull('missingColumn');
// Type error
```

## Model-bound builders

For more convenient column-name type safety, `AstPredicate` can also be called as a generic function.

```ts
import { AstPredicate } from 'ast-predicate';

type EditionTable = {
    code: string;
    TenantCode: string;
    ProductCode: string;
    deletedAt: Date | null;
};

const { and, eq, isNull } = AstPredicate<EditionTable>();

const predicate = and(
    eq('ProductCode', 'product-1'),
    isNull('deletedAt'),
);
```

Invalid column names are rejected by TypeScript.

```ts
const { isNull } = AstPredicate<EditionTable>();

isNull('notExists');
// Type error: "notExists" is not a key of EditionTable.
```

The model-bound builder currently validates column names only. It does not yet validate comparison values against the exact property type of the selected column.

## Destructuring builders

The model-bound builder is designed to be destructured.

```ts
const {
    and,
    or,
    eq,
    isNull,
    isNotNull,
} = AstPredicate<EditionTable>();
```

This keeps predicate definitions concise while preserving column-name type safety.

```ts
const predicate = and(
    isNull('deletedAt'),
    or(
        isNotNull('publishedAt'),
        eq('status', 'ACTIVE'),
    ),
);
```

The root `AstPredicate` object can still be used directly when model binding is not needed.

```ts
const predicate = AstPredicate.isNull('deletedAt');
```

## Validate unknown input

```ts
import { assertAstPredicateNode } from 'ast-predicate';

const input: unknown = JSON.parse(payload);

assertAstPredicateNode(input);

// input is now typed as AstPredicateNode
```

## Restrict allowed columns

```ts
import { AstPredicate, assertAstPredicateColumnsAllowed } from 'ast-predicate';

const predicate = AstPredicate.eq('status', 'ACTIVE');

assertAstPredicateColumnsAllowed(predicate, ['status', 'deletedAt']);
```

This is useful before converting user-provided filters into SQL, ORM conditions, or another query format.

## Transform columns

```ts
import { AstPredicate } from 'ast-predicate';

const predicate = AstPredicate.and(
    AstPredicate.eq('status', 'ACTIVE'),
    AstPredicate.isNull('deletedAt'),
);

const mapped = AstPredicate.mapColumns(
    predicate,
    (column) => `product.${column}`,
);
```

## Collect columns

```ts
import { AstPredicate } from 'ast-predicate';

const predicate = AstPredicate.and(
    AstPredicate.eq('status', 'ACTIVE'),
    AstPredicate.isNull('deletedAt'),
);

const columns = AstPredicate.collectColumns(predicate);
// ['status', 'deletedAt']
```

## Test utilities

`ast-predicate` exposes optional test helpers from a separate subpath.

```ts
import { createCompiledSqlExpect } from 'ast-predicate/test-utils';
```

These helpers are intended for testing SQL generated by predicate adapters or services. They are PostgreSQL-oriented and expect the test framework `expect` function to be passed in by the consumer.

See [test utilities documentation](./docs/test-utils.md) for examples.

## Current scope

This package currently contains the framework-agnostic predicate AST core and optional test utilities.

Adapters may be added later as separate packages or optional modules, for example:

```txt
ast-predicate-kysely
ast-predicate-sequelize
```
